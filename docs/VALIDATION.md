# Первая версия: что реализовано и проверено

Проверки выполнены 14 октября 2026 года в облачной среде. Реальный сервер мероприятия и оборудование площадки в этих проверках не использовались.

## Реализовано

- Однократная настройка по коду из консоли, создание организатора и закрытый вход.
- Настраиваемый брендинг: название, цвета, логотипы, значок сайта, предпросмотр табло и телефона.
- Библиотека вопросов, ответы и очки, источники опросов, импорт и экспорт JSON.
- Подготовка партии из двух команд, порядок вопросов и множители очков.
- Лобби, приглашения и QR-коды команд, назначение капитанов.
- Предложения участников и один официальный ответ капитана на ход.
- Пульт ведущего, табло для гостей, ошибки, перехват, пауза, присуждение банка, исправления, отмена и финальные результаты.
- Черновики на телефоне и восстановление актуального состояния после переподключения.
- Звук табло после явного включения пользователем и поддержка системной настройки уменьшения анимаций.
- PostgreSQL, миграции, сохранение партии и идемпотентные команды.
- Производственный Docker-образ и ручной сценарий GitHub Actions для деплоя.

## Результаты

| --- | --- |
| Установка зависимостей по lockfile, npm ci | Пройдена |
| TypeScript и производственная сборка | Пройдены |
| Vitest: правила и интеграция с PostgreSQL | 29 тестов пройдены, без пропусков |
| Подключения к обновлениям игры | 100 одновременных WebSocket-клиентов получили новую ревизию после действия ведущего |
| Playwright: независимые браузеры ведущего, капитана, игрока, соперника и гостя | Полный сценарий пройден |
| npm audit, включая зависимости разработки | Уязвимостей не обнаружено |
| Docker build на Node.js 24 | Пройден |
| Docker: установка, Secure/HttpOnly cookies, восстановление пароля, загрузка изображения, HTML и JavaScript приложения | Пройдены |
| Замена контейнера | Состояние установки, БД и загруженное изображение сохранились |

Браузерный сценарий включает первый запуск, изменение брендинга, создание своего вопроса, добавление помеченных демовопросов, подготовку игры, предложения участника, выбор и отправку капитаном, открытие ответа ведущим, паузу, сохранение черновика после обновления телефона, начисление банка, следующий раунд и финал. Проверены отсутствие скрытых ответов в публичных JSON и JavaScript, отсутствие чужих предложений на телефоне, мобильная ширина и отсутствие ошибок JavaScript.

Скриншоты создаются текущим запуском в игнорируемой папке `test-results/`. Команды повторения проверок находятся в [README](../README.md).

## Что остаётся для мероприятия

- Подготовить настоящий набор вопросов и результаты опроса; демоданные вымышлены и помечены.
- Уточнить правила и число раундов, дату и ожидаемое число участников.
- Проверить сервер, где уже работают другие сайты, и подготовить отдельное размещение, HTTPS и настройки экземпляра.
- Запустить ручной деплой после подготовки переменных, проверенного ключа сервера и серверного файла настроек.
- Провести репетицию с реальными телефонами, проектором и сетью площадки.
- Проверить серверные резервные копии и процедуру отката на реальном экземпляре.

Раунды «Игра наоборот», «Большая игра», голосования гостей и автономный режим на площадке остаются возможностями следующих версий согласно [плану](../PLAN.md).
